# TireSlot — статичный мокап публичного сайта (`.template/`)

- **Дата:** 2026-09-04
- **Статус:** активный эталон вёрстки (Livewire-реализации ещё нет)
- **Связан с:** `tz/functional-requirements.md` v0.11, `CLAUDE.md` (раздел «Шаблон фронта»)

## Что это

Эталон вёрстки публичного сайта записи: статичный HTML без JS, экран = файл, каждый файл самодостаточен (шапка + контент + футер). При реализации проекта вёрстка переносится с этих страниц в Livewire-шаблоны.

**Решение пользователя (закрепить, не переоткрывать):** порядок шагов записи — сначала время, потом услуги (`ФТ` описывает шаги в обратном порядке, это не менялось).

## Источник дизайна

Мокап создан на основе магазинного шаблона соседнего проекта `../template/.template/` (интернет-магазин шин и дисков «Автоальянс»):

- `assets/` скопированы целиком: `css/style.css` (4701 стр. исходника), `fonts/` (Nunito, Noto Sans), `img/` (51 файл: logo.svg, иконки, соцсети).
- Дизайн-токены и паттерны переиспользуются как есть: `--color-red #dd062a`, рецепт карточки (white + `box-shadow 0 0 20px var(--shadow-1)` + radius 5), `.auth_field`, `.order_form_in`, `.footer-*`, `.social-row`, `.auth_submit`.
- Бренд в мокапе — «Автоальянс» (существующий logo.svg). Телефон: +7 (351) 70-00-319.

## Структура и поток

```
index.html                    # Шаг 1 «Время»: календарь месяца + сетка часов (он же главная)
contacts.html
booking/
  services.html               # Шаг 2 «Услуги»: услуги + радиус + тип авто + опции, сайдбар-итог
  details.html                # Шаг 3 «Данные»: имя, телефон, госномер (опц.)
  code.html                   # Шаг 4 «Подтверждение»: OTP-ввод кода
  success.html                # Запись создана: детали записи (ФТ-11)
  unavailable.html            # Отказ: время занято на момент подтверждения (ФТ-8)
  code-expired.html           # Отказ: код просрочен, 15 мин (ФТ-9)
my-booking/
  index.html                  # Вход по телефону
  code.html                   # Ввод кода (верификация, ФТ-14/ФТ-23)
  list.html                   # Записи клиента: confirmed (>2 ч / <2 ч) и done
  cancelled.html              # Отмена выполнена
assets/                       # css/style.css + дополнения, fonts/, img/ (+calendar/clock/phone/warning.svg)
```

Переходы потока: `index → booking/services → details → code → success`; ошибки ведут обратно на `../index.html` (другое время) или `services.html`. «Мои записи» в шапке — кнопка со значком → `my-booking/index.html` → `code` → `list` → `cancelled`.

Степпер 4 шага на страницах потока: **Время → Услуги → Данные → Подтверждение** (классы `.steps/.step`, состояния `--done` ссылка назад / `--active`).

## Конвенции разработки

- **Без JavaScript** и инлайновых обработчиков: состояния — CSS (`:has(input:checked)` и модификаторы), переходы — ссылки.
- `lang="ru"`; вёрстка desktop-first; брейкпоинты исходника: 1365 / 1023 / 639.
- **Не трогать исходные правила `style.css`** — дополнения только в конец файла, датированными секциями: `/* ===== <Название> (<страницы>) — ГГГГ-ММ-ДД ===== */`.
- Паттерны исходника переиспользовать: `.custom-checkbox-container`/`.service-checkbox` (чекбокс-карточка), `.param-chip` (чип-радио), `.booking-btn-primary/-secondary`, `.auth_card/.auth_field`, карточка `.booking-blk`, `.booking-summary`, `.booking-details`, `.status-badge`.
- Новые иконки — монохромные SVG в `assets/img/`, стиль исходника (stroke/fill по токенам).
- Ссылки: только по реальному потоку (страницы списка/сервисные — `#`).
- Шапка линейная: `.ts-header-row` — лого · таглайн «Шиномонтаж · онлайн-запись» · телефон · кнопка «Мои записи» (иконка login.svg обелена `filter: brightness(0) invert(1)`).

**Чек-лист новой страницы:** скопировать каркас с шапкой/футером из существующей; поправить пути (`./assets` в корне, `../assets` в подпапках); корректный степпер; согласованные данные сценария; CSS-секция в конец style.css с датой; `lang="ru"`, без JS; проверить на 1366/1024/640.

## Верификация

Открыть: `cd .template && python3 -m http.server 8765`. Проверить проход по потоку и состояния (календарь: 1 сентября 2026 — вторник, воскресенья выходные; OTP: focus и `--error`; бейджи confirmed/done; отсутствие горизонтального скролла на 1366/1024/640). Автопроверка: валидация всех страниц (баланс тегов, целостность ссылок, `lang="ru"`, отсутствие JS) — python-скриптом по шаблону в истории сессии.

## Известные заглушки

- `.map-placeholder` в contacts — «карта проезда» (интеграция 2ГИС/Яндекс вне рамок v1 по ФТ).
- Кнопка «Заказать звонок» в шапке/футере — без действия (в исходном шаблоне тоже декоративная).
- «Мои записи» при пустом списке: экран `.booking-list-empty` свёрстан в CSS, страница не создана.
