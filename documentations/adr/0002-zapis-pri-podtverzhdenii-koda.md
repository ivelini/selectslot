# 0002. Запись создаётся только при подтверждении кода

- **Статус:** Accepted
- **Дата:** 2026-09-04
- **Связанные ADR:** 0001, 0003

## Контекст
Клиент виджета выбирает время и вводит данные. Классический сценарий: создать запись в промежуточном статусе и держать слот на таймаут, пока клиент подтверждает SMS-код.

## Решение
Запись создаётся только при вводе кода — сразу в статусе `confirmed`. До подтверждения данные заявки хранятся вместе с кодом; слот не удерживается. Из админки запись создаётся сразу.

## Почему (альтернативы)
Слот-час не ограничен по числу записей (ADR 0003) — удерживать его за клиентом нечего. Промежуточный статус дал бы висящие записи в календаре оператора и крон истечения, не давая взамен защиты времени. Цена: клиент, подтвердивший поздно, может получить отказ «время недоступно» (слот успели закрыть) — обрабатывается как повторный выбор.

## Последствия
Статусная машина без промежуточного состояния, календарь содержит только реальные записи. Пересмотрим, если появится лимит на час или посты — тогда вернётся смысл резерва с удержанием слота.
