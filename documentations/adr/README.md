# ADR — архитектурные решения

База решений: «почему система устроена так». Пишется при принятии решений с реальной развилкой (при закрытии плана, изменении границ сервисов, выборе паттернов). Анти-правила: без деталей реализации и решений без развилки. Правила ведения — в `.claude/rules/adr.md`, шаблон — `0000-template.md`.
