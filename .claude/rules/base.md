# Завершение задачи (ОБЯЗАТЕЛЬНО)

ПЕРЕД завершением задачи / финальным отчётом нужно ОБЯЗАТЕЛЬНО выполнить проверку wiki-sync:

1. Оценить, затрагивают ли изменения бизнес-логику или функционал (см. .claude/rules/wiki-sync.md)
2. Если ДА — задать пользователю вопрос в чате с предложением обновить wiki, ДО завершения задачи
3. Если НЕТ (косметические изменения) — можно завершить задачу

Не завершать задачу без прохождения этой проверки.
