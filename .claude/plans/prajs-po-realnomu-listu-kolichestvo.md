# Прайс по реальному прайс-листу: оси правил без опций, количество колёс

- **Дата:** 2026-09-09
- **Статус:** согласован, реализация

## Цель

Перевести каталог и прайс-правила на реальный прайс-лист шиномонтажа: цена зависит от (услуга, радиус, тип), цена — за 1 колесо/шт, клиент задаёт количество 1–4. RunFlat/TPMS перестают быть параметрами авто (в прайсе это доп. работы).

## Решения (согласованы)

- **Оси правил:** (услуга, радиус R13–R21 поштучно, тип). Цены прайс-групп R12–15 / R16–17 / R18–19 / R20–21 разворачиваются на радиусы; passenger = «легковые», crossover и suv = общая «внедорожная» колонка (одинаковые цены). R22 в прайсе нет — убрать из `WheelRadiusEnum` (R13–R21).
- **Каталог (10 услуг):** работы с правилами — «Снятие и установка колёс», «Демонтаж колёс», «Монтаж колёс», «Балансировка колёс», «Комплекс работ (1 колесо)» (проверка: комплекс = сумма четырёх работ); допработы без правил (база за шт) — «Замена вентиля» 50 ₽, «Установка датчика давления (TPMS)» 100 ₽, «Монтаж/демонтаж шин RunFlat» 100 ₽, «Покрытие ступицы антикоррозийной смазкой» 100 ₽, «Утилизация шины» 200 ₽. Комплектные строки («Комплекс 4 колеса», «при покупке −20%») не заводим.
- **Количество:** у каждой выбранной услуги счётчик 1–4 (дефолт 4 при выборе); итог = Σ цена_правила × кол-во; `price` в правилах и снимке — за единицу; строка итога — `price × quantity`.
- **RunFlat/TPMS удаляются везде:** `price_rules`, `bookings`, `cars` (миграция), `VehicleParams` = radius + carType, шаг «Услуги» без чипов опций, URL без runflat/tpms.
- Ценовая политика ADR 0007 сохраняется: полный куб (5×9×3 = 135 правил), 0 правил = база, отсутствие комбинации = ошибка.

## Задачи

1. Миграция: drop `has_runflat`/`has_tpms` (price_rules, bookings, cars), unique price_rules → (service_id, radius, car_type), `booking_services.quantity` (1–4). Правки моделей/фабрик/PHPDoc.
2. `VehicleParams` (radius, carType), `PricingCalculator::quote(services, params, quantities)` — строки {service, unit_price, quantity, price}, total.
3. `WheelRadiusEnum` R13–R21; `ServicesStepPage`: без опций, счётчики (toggle → qty 4, ±1 в границах 1–4), quantities id=>qty в `#[Url]`, чистка пар.
4. Сид `CatalogSeeder` по прайсу (135 правил, контрольные цены); старые услуги удаляются; `DemoBookingSeeder` — новые имена, расчёт через `PricingCalculator` (демо-копия удаляется); правки фабрик.
5. Мокап `services.html`: карточки услуг по прайсу («за 1 колесо»), без группы опций, сайдбар со строками «×N», сценарий: R16 кроссовер: снятие ×4 = 1 200 ₽, балансировка ×4 = 1 200 ₽, итог 2 400 ₽.
6. Документация: ФТ v0.13 (ФТ-2/ФТ-4/глоссарий), db-schema (опции убраны, quantity), ADR 0007 (оси без опций), вики (после ответа на вопрос).
