# Публичный сайт: шаг «Услуги» (GET /booking/services) + расчёт цены

- **Дата:** 2026-09-08
- **Статус:** согласован, реализация

## Цель

Шаг 2 публичной записи (мокап `booking/services.html` → Livewire): выбор услуг и параметров авто с живым серверным пересчётом цены по прайс-правилам (ФТ-4/ФТ-5). Состояние — в query (ADR 0006).

## Решения (согласованы)

- Сайдбар: строки «услуга — фактическая цена по правилу» + итог; наценки-строки из мокапа не переносятся.
- Расчёт — единый `PricingCalculator` для показа и подтверждения (НФ-4). Подбор **только точным совпадением** (услуга, радиус, тип, runflat, tpms):
  - у услуги 0 правил → цена не зависит от параметров → `base_price`;
  - правила есть, комбинации нет → `PricingException` (fail fast: потерянное правило — баг данных, не молчаливая база);
  - на UI ошибка ловится: «Цена недоступна — позвоните в мастерскую», «Продолжить» заблокирован (страница не падает 500).
- Сид: полный куб правил «Снятие/установка» — R13–22 × {легковая, кроссовер, внедорожник} × runflat×2 × tpms×2 = 120 правил; tpms-наценка +400 ₽ (мокап); truck в куб не входит.
- «Грузовик» и «Не знаю» на сайте нет: типы выбора — `CarTypeEnum::bookable()` (без Truck, грузовики — по звонку ФТ-18); радиус — R13–R22 (enum `WheelRadiusEnum`); параметры (радиус, тип) обязательны к переходу, опции RunFlat/TPMS — опциональны.
- «Продолжить» активна ⇐ ≥1 услуга ∧ радиус ∧ тип (полный набор) ∧ цена определена. Ссылка несёт весь выбор в query (`booking.details`).
- Вход без валидного date/time (мусор/слот закрыт) → redirect на `booking.time`.
- «Изменить время» ведёт на шаг 1 с date/time (выбор услуг при этом сбрасывается — принято).
- Общий код: `Reader::isSelectableHour()` (TimeStepPage переводится на него), утилиты `App\Support\RussianDate` и `Money` (TimeStepPage переводится на RussianDate — убрать дубли массивов).

## Сопутствующие правки

- Мокап `.template/booking/services.html`: убрать «Не знаю» (радиус/тип), «Грузовик», подписи `param-chip-note`, surcharge-строки сайдбара (заменить строками услуг с фактическими ценами сценария: снятие 1 300 ₽, балансировка 400 ₽, итог 1 700 ₽), подсказки про «не знаю»/наценки.
- Сид `CatalogSeeder`: куб правил до R22 с tpms (комментарий-формула обновить).
- ФТ v0.12 (`documentations/tz/functional-requirements.md`): ФТ-2 (нет правила для параметрной услуги — ошибка конфигурации; услуги без правил — база), ФТ-4 (без «не знаю»; радиус/тип обязательны; грузовики — по звонку).

## Ожидаемый результат

GET /booking/services при валидном выборе времени показывает каталог активных услуг, чипы радиуса/типа/опций; полный набор даёт живые цены строк и итог; «Продолжить» открывает шаг «Данные» с выбором в URL. Тесты зелёные.
