# Публичный сайт: каркас маршрутов записи и шаг «Время» (GET /)

- **Дата:** 2026-09-08
- **Статус:** согласован, реализация

## Цель

Работающий шаг «Время» публичной записи на реальных слотах (мокап `index.html` → Livewire) + каркас маршрутов ветки записи (ADR 0006: страницы на шаг, состояние выбора в query).

## Задачи

1. **Каркас маршрутов.** 4 маршрута ветки: `booking.time` (GET /), `booking.services`, `booking.details`, `booking.code` — full-page Livewire-компоненты; шаги 2–4 — заглушки со степпером (их механика — следующими планами). Layout публичного сайта: перенос ассетов `.template/assets` → `public/assets`, шапка/степпер/футер из мокапа. Пункты «Мои записи»/«Контакты» не выводятся до реализации веток (ссылки — только по реальному потоку).
2. **`App\Services\SlotAvailabilityReader`** — единый источник правила доступности (НФ-4): чтение сетки для показа; подтверждение кода (ФТ-8) в будущем использует то же правило с блокировкой строки.
3. **`App\Livewire\Booking\TimeStepPage`** — календарь месяцев + сетка часов, выбор в `#[Url]`-параметрах (date=Y-m-d, time=H:00), переход на шаг услуг.

## Решения (согласованы)

- Единый доменный сервис доступности вместо запросов из компонента.
- Чистый вход / невалидный date из query — **день не выбирается автоматически**: календарь на текущем месяце, сетка часов пустая до клика по доступному дню. Невалидный (мусор/вне горизонта/прошлый) date и недоступное time из query **сбрасываются**, не нормализуются.
- День в календаре кликабелен ⇐ ∃ открытый слот в лимитах (граница для today: начало ≥ now+min_lead, округление вверх до часа; горизонт — настройка booking_horizon_days, по умолчанию 30 дней: today..today+29).
- Прошедшие часы дня не показываются; закрытые (is_closed) будущие часы — busy-чипы (ФТ-6). Шаблон недели (`schedule_templates`) сайт не читает — состояние дня по слотам.
- «К выбору услуг» — ссылка на `booking.services` с date/time; без выбранного времени неактивна.
- Чтение настроек — как `SlotGridGenerator` (`Setting::find('key')?->value ?? default`).

## Ожидаемый результат

GET / отдаёт страницу шага «Время»: календарь (текущий месяц, листание до месяца горизонта), клик по доступному дню → сетка часов, клик по часу → выбор, ссылка на `/booking/services?date=…&time=…`. Тесты зелёные.
