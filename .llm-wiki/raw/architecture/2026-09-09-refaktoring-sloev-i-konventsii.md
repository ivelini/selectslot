# Рефакторинг доменного слоя и шагов записи (2026-09-09)

> Source: Код репозитория TireSlot (рабочая ветка master, серия рефакторингов 09.09.2026): app/, config/, database/, tests/
> Collected: 2026-09-09
> Published: 2026-09-09

Серия согласованных рефакторингов: разведение каталогов доменного слоя (ADR 0010), единая конвенция действий, параметры конфигурации в enum-словаре, вынос общего кода шагов записи. Ключевые факты:

- **Каталоги (ADR 0010):** `app/Actions/` — однооперационные действия `{Глагол}{Существительное}Action` с единственным публичным `handle()`: `CreateBookingAction` (создание записи при подтверждении кода, бывш. `BookingCreator`), `CalculatePriceAction` (расчёт цены, бывш. `PricingCalculator`, переехал из Services), `GenerateSlotGridAction` (генерация сетки, бывш. `SlotGridGenerator`). `app/Services/` — службы областей: `BookingCodeService`, `SlotAvailabilityReader` + адаптер `LogSmsSender`. Критерий — гранулярность (одно публичное действие vs набор операций области), CQS соблюдается внутри класса.
- **CQS-чистка:** запрос `bookingForCode` вынесен из действия на модель: `Booking::forCode(BookingCode): ?Booking` (повторный submit использованного кода, НФ-1).
- **Параметры конфигурации:** ключи/дефолты таблицы settings собраны в `app/Enums/Settings/SettingKeyEnum` (ReservationTimeoutMin 15, MinLeadTimeH 1, HorizonDays 30); чтение — только `Setting::get(SettingKeyEnum::…)`. Кулдаун повторной SMS (60 с, не параметр таблицы 7 ФТ) — `config/services.php` → `services.sms.resend_cooldown_seconds`.
- **Общий код шагов записи:** `app/Support/BookingQuery` — чистые функции контракта query (ADR 0006): `parseDate` (строгое «Y-m-d» с round-trip), `parseTimeHour` (только «HH:00» — сайт даёт целые часы), `normalizeQuantities` (дефолт 4 — сезонный комплект, границы 1–4), `carTypeValueOrNull` (не bookable → null); константы DEFAULT/MIN/MAX_QUANTITY. Скоуп `Service::scopeActiveByIds` — нормализация устаревшего выбора услуг.
- **Каркас шагов выбора (Livewire):** шаги 2–4 перенесены в подкаталог `app/Livewire/Booking/SelectionStepPage/` (неймспейс `App\Livewire\Booking\SelectionStepPage`): абстрактный `SelectionStepPage` (общие `#[Url]`-поля выбора; `mount`: guard «время выбираемо» → redirect на шаг 1 → нормализация выбора → `afterMount()` — специфика шага; `selectionDateTime()` — формат, `selectableDateTime(reader)` — формат + окно + слот; `selectionQueryParams()` — массив для route) + `ServicesStepPage`/`DetailsStepPage`/`CodeStepPage` — наследники. Guard в `confirmBooking` шага «Код» — только формат (`selectionDateTime`), не доступность слота: закрытый слот ловит `CreateBookingAction` → редирект unavailable (поведение зафиксировано тестом `test_slot_closed_redirects_to_unavailable`). Шаг «Время» (`TimeStepPage`) — вне каркаса.
- **Enum'ы записей** перенесены в `app/Enums/Booking/`: `BookingStatusEnum`, `BookingSourceEnum`.
- **Тесты** переехали зеркально: `tests/Unit/Actions/{CreateBookingAction,CalculatePriceAction,GenerateSlotGridAction}Test`, `tests/Unit/Support/BookingQueryTest`, `tests/Unit/Models/Booking/BookingTest` (границы `Booking::forCode`), `tests/Unit/Models/SettingTest` (Setting::get + дефолты таблицы 7 ФТ). Фабрика `Booking` — `newFactory()` на модели + `#[UseModel]` (модель в подпапке).
