# Статичный мокап публичного сайта (.template/)

> Sources: TireSlot template-mockup.md, 2026-09-04
> Raw: [template-mockup.md](../../raw/frontend/2026-09-04-template-mockup.md)

## Overview

Эталон вёрстки публичного сайта записи: статичный HTML **без JS**, экран = файл (каждый файл самодостаточен: шапка + контент + футер). При реализации вёрстка переносится с этих страниц в Livewire-шаблоны ([архитектура](../architecture/application-architecture.md)). Ассеты (css/fonts/img) скопированы из магазинного шаблона соседнего проекта (интернет-магазин «Автоальянс»); бренд в мокапе — «Автоальянс», телефон +7 (351) 70-00-319.

**Решение пользователя (не переоткрывать):** порядок шагов записи — сначала время, потом услуги. Это расходится с порядком изложения в ФТ (услуги → время): мокап фиксирует фактический поток, см. [booking-flow](../domain/booking-flow.md).

## Структура и поток

```
index.html                 # Шаг 1 «Время»: календарь месяца + сетка часов (он же главная)
booking/services.html      # Шаг 2 «Услуги»: услуги с количеством + радиус + тип, сайдбар-итог
booking/details.html       # Шаг 3 «Данные»: имя, телефон, госномер (опц.)
booking/code.html          # Шаг 4 «Подтверждение»: OTP-ввод кода
booking/success.html       # Запись создана (детали, ФТ-11)
booking/unavailable.html   # Отказ: время занято на подтверждении (ФТ-8)
booking/code-expired.html  # Отказ: код просрочен (ФТ-9)
my-booking/index.html      # Вход по телефону
my-booking/code.html       # Ввод кода (верификация, ФТ-14/23)
my-booking/list.html       # Записи: confirmed (>2 ч / <2 ч) и done
my-booking/cancelled.html  # Отмена выполнена
contacts.html
```

Степпер 4 шага: **Время → Услуги → Данные → Подтверждение**. «Мои записи» в шапке → `my-booking/index` → `code` → `list` → `cancelled`. Ошибки ведут обратно: на выбор другого времени или услуг.

## Единый сценарий мокапа (заглушки)

Все страницы фиксируют один набор данных — менять согласованно: мастерская «г. Челябинск, Копейское шоссе, 12А; Пн–Сб 9:00–19:00 (обед 13–14), Вс — выходной»; запись «11 сентября 2026 (пт) 11:00, № TS-000123»; услуги каталога реального прайса (карточки «от 150 ₽» и т.п., цены за 1 колесо); сценарий: «Снятие и установка колёс» + «Балансировка колёс», ×4, R16, кроссовер — сайдбар: 1 200 ₽ + 1 200 ₽, итог 2 400 ₽, у строк счётчики «− × 4 +» (карточки списка: 4 сентября 17:00 — 2 100 ₽; 3 сентября done — 1 050 ₽); телефон +7 951 123-45-67, код SMS 4812; недоступные слоты 13:00 (обед) и 16:00 (закрыт).

## Конвенции разработки

- Без JavaScript: состояния — CSS (`:has(input:checked)`), переходы — ссылки.
- `lang="ru"`, desktop-first; брейкпоинты исходника 1365/1023/639.
- Исходные правила `style.css` не трогать: дополнения — в конец файла датированными секциями `/* ===== <Название> (<страницы>) — ГГГГ-ММ-ДД ===== */`; новые иконки — монохромные SVG в `assets/img/`.
- Переиспользовать паттерны исходника: чекбокс-карточка `.service-checkbox`, чип-радио `.param-chip`, `.booking-btn-primary/-secondary`, `.auth_card/.auth_field`, `.status-badge`.
- Ссылки — только по реальному потоку; шапка линейная `.ts-header-row`.

## Соответствие ФТ

index ↔ ФТ-6/ФТ-10 (мин. 1 ч, горизонт 30 дней, закрытые слоты); services ↔ ФТ-4/ФТ-5 (итог до бронирования, обязательные радиус/тип, количество 1–4, цены за единицу × количество в сайдбаре); details/code ↔ ФТ-7/ФТ-8/ФТ-9 (TTL 15 мин); success ↔ ФТ-11; my-booking/list ↔ ФТ-12/ФТ-14/ФТ-21; my-booking/index+code ↔ ФТ-23; contacts ↔ ФТ-11.

Верификация: `cd .template && python3 -m http.server 8765`; проверка без горизонтального скролла на 1366/1024/640.

Известные заглушки: `.map-placeholder` (карта — вне v1), кнопка «Заказать звонок» (декоративная), пустой список «Мои записи» (CSS свёрстан, страницы нет).
