# Цены: прайс-правила, расчёт, снимок в записи

> Sources: TireSlot ФТ v0.11, 2026-09-08; db-schema v0.8, 2026-09-08; ADR 0004, 2026-09-04
> Raw: [ФТ v0.11](../../raw/domain/2026-09-08-functional-requirements.md); [db-schema v0.8](../../raw/domain/2026-09-08-db-schema.md); [ADR 0004](../../raw/architecture/2026-09-04-0004-snimok-tseny-v-zapisi.md)

## Overview

Цена услуги зависит от услуги, радиуса колеса, типа авто и опций. Расчёт ведётся по единым правилам для всех каналов записи (виджет и админка) и показывается клиенту до бронирования. Запись хранит **снимок** параметров и цен на момент создания: прайс, изменённый задним числом, на созданные записи не влияет (ADR 0004) — согласованная сумма это исторический факт, а осознанное исключение из общего правила «связанные сущности — через relation».

## Каталог услуг (ФТ-1)

Услуги: название, категория (`tire` / `storage` / `other`), признак активности, базовая цена. Неактивные не видны клиенту и не участвуют в записи. Услуги управляются из админки без деплоя; длительность не моделируется — только цена (ADR 0003).

## Прайс-правила (ФТ-2)

Правило — комбинация (услуга, радиус R13–R22, тип авто, опции RunFlat/TPMS) с ценой. Подбор по убыванию точности:

1. точное совпадение (услуга, радиус, тип, опции);
2. правило той же услуги без опций (`has_runflat=false, has_tpms=false`);
3. `services.base_price` — fallback, если правила для комбинации нет.

Параметры клиент выбирает в заявке; если радиус/тип неизвестны — поля обязательные с вариантом «не знаю» → базовый тариф (ФТ-4). Изменение правил применяется сразу к новым записям.

## Снимок в записи (ADR 0004, ФТ-19)

При создании записи фиксируются: радиус, тип авто, опции, `total_price`, цены строк состава (`booking_services.price`). Заявка до подтверждения не хранится: при вводе кода цена пересчитывается сервером по актуальным правилам из выбора клиента и фиксируется в записи — показ итога и создание используют один расчёт (ФТ-8). Оператор может скорректировать цены строк и итог в админке (ручная скидка/наценка по договорённости). Пересмотр: если появится версионирование прайса — снимок заменится ссылкой на версию.
